# Черновик резюме «Помощник психолога» — что заполнить и как доработать

## Статус

В репозитории **не было** отдельного резюме под психологию. Создан черновик: `resume_pomoshnik_psikhologa.md`.

## Что нужно от вас для финальной версии

1. **Переподготовка «Психолог-консультант»**
   - Полное название учебного заведения (НАДПО / вуз)
   - Год окончания
   - Номер диплома (по желанию — для HH можно без номера)
   - Часы программы (если указаны в дипломе)

2. **Практика / стажировка** (если была по программе переподготовки)
   - Где проходила, сколько часов, какие задачи

3. **Желаемый формат**
   - Только помощник психолога или также «психолог-консультант» (начинающий)?
   - Зарплатные ожидания
   - Частичная занятость / вечер (если актуально)

## Сильные стороны вашего профиля для «помощника психолога»

| Фактор | Почему важно |
|--------|----------------|
| Переподготовка «Психолог-консультант» | Профильное образование — часто ключевое требование |
| МГПУ, педагогический вуз | Смежная база для работы с людьми и документами |
| Консультант суда | Документы, конфиденциальность, анализ текстов |
| Совэлмаш (образовательная сфера) | Контекст работы с людьми в учреждении |
| ISBC | Консультации, инструкции, реестры, отчёты |

## Что сознательно не включено (нет в фактах)

- Опыт проведения психологических консультаций
- Методы терапии, тестирование клиентов
- SMM / копирайтинг (если не подтвердите отдельно)

## Типичные обязанности по вакансиям (Москва / Зеленоград, 2026)

- Запись клиентов, напоминания, календарь
- Документооборот: договоры, анкеты, таблицы
- Подготовка материалов к сессиям, вебинарам, группам
- Административная поддержка частного психолога или центра
- Иногда — удалённая работа, онлайн-школы

**Зеленоград (hh.ru):** профильных вакансий мало (1–2 по запросу «помощник психолога»); основной рынок — Москва, часто удалённо.
