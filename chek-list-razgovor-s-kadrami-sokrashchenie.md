# Чек-лист: разговор с кадрами при сокращении

> Для встречи / звонка с HR при уведомлении об увольнении по сокращению (п. 2 ст. 81 ТК РФ).  
> Распечатайте или держите открытым на телефоне. **Ничего не подписывайте в день первого разговора** — попросите копии и время на изучение (1–3 дня).

---

## Перед разговором

- [ ] Записать дату и время встречи, ФИО и должность собеседника из HR
- [ ] Включить диктофон **только если это законно в вашем регионе** или вести письменные заметки
- [ ] Подготовить: паспорт, трудовую книжку / выписку СТД-Р, трудовой договор, должностную инструкцию
- [ ] Напомнить себе: вы вправе **не подписывать** документы сразу и **не соглашаться** на «собственное» или «по соглашению» без оценки условий

---

## 1. Уточнить основание увольнения

Спросить прямо:

- [ ] **По какой статье ТК РФ** планируется увольнение? (нужно: **п. 2 ч. 1 ст. 81** — сокращение штата/численности)
- [ ] Это **сокращение должности** или другое основание (соглашение сторон, «неэффективность» и т.п.)?
- [ ] **Какая именно должность** сокращается в штатном расписании?
- [ ] Есть ли **приказ о сокращении** и **новое штатное расписание**? Прошу **копии**

**Красные флаги:** «давайте по собственному», «по статье за нарушения», «соглашение сторон без альтернативы», отказ назвать статью ТК РФ.

---

## 2. Сроки и уведомление

- [ ] **Дата увольнения** (не раньше чем через **2 месяца** после получения уведомления, если нет вашего письменного согласия на раньше)
- [ ] **Дата вручения уведомления** — зафиксировать в акте / на экземпляре уведомления
- [ ] Получить **письменное уведомление** о предстоящем увольнении (экземпляр с вашей подписью о получении или отметкой об отказе подписать)
- [ ] Уточнить: уведомление вручается **лично** или **заказным письмом** (email/мессенджер — **не замена** без КЭДО)

**Записать:** дата уведомления ______ → самая ранняя дата увольнения ______

---

## 3. Вакансии и перевод

- [ ] Просьба предоставить **полный письменный перечень всех вакансий** в данной местности (в т.ч. ниже по должности и оплате)
- [ ] Есть ли вакансии в **других подразделениях / на удалёнке**?
- [ ] Какой **срок** на рассмотрение предложений?
- [ ] Если вакансия подходит — как оформляется **перевод** (допсоглашение, приказ)?

**Сказать:** «Прошу направить перечень вакансий письменно. Устных предложений недостаточно — нужен документ для ознакомления».

---

## 4. Преимущественное право остаться (ст. 179 ТК РФ)

- [ ] По каким критериям выбрали, **кого сокращают**, а кого оставляют?
- [ ] Учтены ли: квалификация, производительность, **иждивенцы**?
- [ ] Есть ли среди остающихся сотрудники с **равной квалификацией** (в т.ч. вернувшиеся с военной службы — с 01.09.2026)?
- [ ] Попадаю ли я под **защиту от сокращения** (ст. 261): беременность, дети до 3 лет, одинокий родитель и др.?

**Если есть основания для защиты** — озвучить и попросить письменный ответ.

---

## 5. Выплаты при увольнении

Попросить **письменный расчёт** (можно предварительный):

| Выплата | Сумма / порядок | Отметка |
|--------|------------------|--------|
| Зарплата за отработанное | | ☐ |
| Компенсация неиспользованного отпуска | | ☐ |
| **Выходное пособие** (1 средний месячный) — в день увольнения | | ☐ |
| **2-й месяц** (ещё 1 средний) — при нетрудоустройстве, по заявлению | | ☐ |
| **3-й месяц** — только по решению ЦЗН | | ☐ |
| Доплата при **досрочном** увольнении с вашего согласия | | ☐ |
| Премии, бонусы, «13-я» — по положению о премировании | | ☐ |

**Вопросы HR:**

- [ ] Как считается **средний заработок**? Прошу **расчётный лист**
- [ ] Все выплаты — **в день увольнения** (ст. 140 ТК РФ), кроме 2–3 месяца по заявлению?
- [ ] Куда и **в какой срок** подавать заявление на выплату за 2-й месяц?
- [ ] Нужны ли справки из ЦЗН для **2-го месяца**? (по закону — **нет**, достаточно трудовой / СТД-Р без новой работы)
- [ ] Предлагают ли **единовременную компенсацию** (2 средних) вместо помесячных — **сравнить суммы** перед подписанием

**Красные флаги:** «второй месяц не положен», «выплатим только выходное», «подпишите отказ от претензий», давление подписать в день разговора.

---

## 6. Альтернатива: соглашение сторон

Если предлагают **увольнение по соглашению** (ст. 78) вместо сокращения:

- [ ] **Размер компенсации** (часто торгуют: 2–4+ оклада)
- [ ] Сравнить с гарантиями при сокращении: выходное + 2-й месяц + возможный 3-й через ЦЗН + пособие по безработице
- [ ] Срок выплаты, налогообложение (НДФЛ), **нет ли отказа от всех претензий** в заниженной формулировке
- [ ] **Право отказаться** — соглашение только по взаимному согласию

**Не подписывать соглашение**, пока не посчитали выгоду и не проконсультировались (юрист / профсоюз / ЦЗН).

---

## 7. Документы — что получить на руки (копии)

- [ ] Уведомление о предстоящем увольнении
- [ ] Приказ о сокращении / штатном расписании (или выписка)
- [ ] Перечень вакансий
- [ ] Проект приказа об увольнении (когда будет)
- [ ] Расчётный лист / справка о среднем заработке
- [ ] Справка 2-НДФЛ (по запросу)
- [ ] Копия трудовой / СТД-Р при увольнении

---

## 8. Больничный, отпуск, отработка

- [ ] Если на **больничном** — увольнение только после выхода (кроме ликвидации)
- [ ] **Неиспользованный отпуск** — компенсация или отпуск с последующим увольнением?
- [ ] Нужна ли **отработка** при сокращении? (обычно **нет** двухнедельной отработки, в отличие от увольнения по собственному)
- [ ] Можно ли взять **отпуск** до даты увольнения?

---

## 9. После увольнения — что спросить заранее

- [ ] Контакты для расчётов и **заявления на 2-й месяц**
- [ ] Как получить **трудовую / СТД-Р**, справки
- [ ] Рекомендации, **служебная характеристика** (если нужны для поиска работы)
- [ ] **Регистрация в ЦЗН** — в течение 14 рабочих дней для возможной выплаты за 3-й месяц и пособия по безработице

---

## 10. Чего не делать на встрече

- [ ] Не подписывать **заявление по собственному** «чтобы быстрее»
- [ ] Не подписывать **соглашение о расторжении** без расчёта и времени на размышление
- [ ] Не подписывать **отказ от вакансий**, если вакансии не предлагали письменно
- [ ] Не соглашаться устно на «отказ от претензий» и «всё получил»
- [ ] Не грубить — фиксировать факты; при давлении: «Мне нужны документы в письменном виде, я вернусь с ответом после изучения»

---

## 11. Фразы, которые можно использовать

**Про основание:**  
«Уточните, пожалуйста, пункт статьи 81 ТК РФ и приложите копию приказа о сокращении штата».

**Про сроки:**  
«Прошу вручить уведомление за 2 месяца до даты увольнения и указать дату увольнения в документе».

**Про вакансии:**  
«Направьте полный перечень вакансий в письменном виде — я рассмотрю и дам ответ».

**Про выплаты:**  
«Прошу предварительный расчёт всех выплат, включая выходное пособие и порядок получения выплаты за второй месяц по ст. 178 ТК РФ».

**Про время:**  
«Я не готов подписывать документы сегодня. Прошу передать копии для ознакомления».

---

## 12. После разговора — ваши шаги

- [ ] Переписать заметки / сохранить запись в безопасное место
- [ ] Проверить даты и суммы по ТК РФ или с юристом
- [ ] Зарегистрироваться в **ЦЗН** (если планируете — в срок 14 рабочих дней после увольнения)
- [ ] После увольнения: **заявление на 2-й месяц** — не позднее 15 рабочих дней после окончания 2-го месяца
- [ ] Обновить план откликов / резюме

---

## Краткая памятка по суммам (сокращение)

```
День увольнения:     1 средний месячный (выходное пособие) + зарплата + отпуск
Если не устроились:  +1 средний за 2-й месяц (по заявлению)
Итого от работодателя: до 2 средних месячных (без ЦЗН на 3-й)
```

---

*Не является юридической консультацией. При споре — ГИТ, ЦЗН, профсоюз, юрист по трудовому праву.*
