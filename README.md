# proba_rezume

Материалы по резюме и поиску работы. Репозиторий настроен для работы **из разных мест** через Cursor Cloud.

## Как работать из разных мест

1. Войдите в [Cursor](https://cursor.com) (Desktop, Web или Mobile) под одним аккаунтом.
2. Подключите GitHub-аккаунт `borisglushkov-collab`, если ещё не подключён.
3. Запустите **Cloud Agent** на этом репозитории: [cursor.com/agents](https://cursor.com/agents).
4. Агент правит файлы в облаке, коммитит и открывает PR в `main`.
5. С другого устройства откройте тот же агент или новый Cloud Agent на нужной ветке.

Локальные копии на одном компьютере не обязательны: источник истины — GitHub.
