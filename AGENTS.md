# AGENTS.md — proba_rezume

Репозиторий материалов по резюме и поиску работы (Глушков Владимир).
Источник истины: GitHub `borisglushkov-collab/proba_rezume`.

## Режим работы: Cloud (из разных мест)

Этот проект настроен для **Cursor Cloud Agents**.

- Работайте через [cursor.com/agents](https://cursor.com/agents) или Agents Window в Cursor Desktop / Web / Mobile.
- Выбирайте режим **Cloud**, репозиторий `borisglushkov-collab/proba_rezume`.
- Не опирайтесь на локальные папки на одном ПК (`rezume`, `proba_rezume-worktree`) как на источник истины.
- Все правки агент коммитит и пушит в GitHub; продолжение с другого устройства — через тот же remote и cloud-агента.

### Как продолжить с другого места

1. Откройте Cursor (Desktop / Web / Mobile) под тем же аккаунтом.
2. Запустите Cloud Agent на `borisglushkov-collab/proba_rezume`.
3. Укажите ветку задачи или `main`, если начинаете новую.
4. Проверьте открытые PR и прошлые агенты: [cursor.com/agents](https://cursor.com/agents).

### Что не делать

- Не копировать файлы вручную между компьютерами вместо git push/pull.
- Не считать локальный worktree единственной рабочей копией.
- Не коммитить секреты (токены, пароли) в файлы репозитория.

## Cursor Cloud specific instructions

- Окружение задаётся в `.cursor/environment.json`.
- Это документный репозиторий: нет `npm`/`pip` install. После старта достаточно проверить git remote и список файлов.
- Правки резюме и промптов делайте в markdown/txt; PDF/DOCX обновляйте только если пользователь явно просит.
- Перед завершением задачи: `git add`, `git commit`, `git push`, затем PR в `main`.
- Предпочитаемая base-ветка для PR: `main`.
- Язык ответов пользователю: русский, если он пишет по-русски.
